# Apeironix Skills

### Open AI Skills for Insurance Professionals

Apeironix Skills is a public library of reusable Markdown-based AI Skills designed around real insurance workflows.

These Skills are intended for insurance professionals, agencies, developers, and AI builders who want practical starting points for applying AI to insurance work.

Our goal is simple:

**Turn repeatable insurance expertise into reusable AI capabilities.**

## How Apeironix Skills Work

Each Skill is designed to define:

- Purpose
- When the Skill should be used
- Required inputs
- Optional inputs
- Workflow steps
- Insurance-specific decision rules
- Output requirements
- Quality checks
- Guardrails
- Example use

Most Skills are stored as `SKILL.md` files inside a dedicated workflow folder.
